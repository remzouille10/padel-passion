# Padel Track — version confort

## Fichiers
Tous les fichiers nécessaires sont à la racine de cette archive : `index.html`, `style.css`, `app.js`, `logo-padel.jpg` et `README.md`. Aucun dossier imbriqué n'est nécessaire.

## Mise à jour sur GitHub Pages
1. Décompresse l'archive.
2. Ouvre le dépôt GitHub de l'application.
3. Dans **Add file → Upload files**, glisse directement les cinq fichiers à la racine du dépôt.
4. Accepte le remplacement de `index.html`, `style.css` et `app.js`, et ajoute `logo-padel.jpg`.
5. Clique sur **Commit changes**.
6. Attends le déploiement GitHub Pages, puis recharge l'application.

## Utilisation et sauvegarde
- Les données sont stockées dans le navigateur utilisé pour l'application.
- Exporte régulièrement une sauvegarde depuis Apparence → Préserver tes données.
- Après une mise à jour, les matchs enregistrés dans le même navigateur restent normalement disponibles. Ne vide pas les données du site avant d'avoir exporté une sauvegarde.
- Si un match n'apparaît pas, vérifie que tu utilises le même navigateur et la même adresse GitHub Pages, puis recharge la page.

Les statistiques sont maintenant saisies par fourchettes afin de limiter les estimations trop précises. Les conseils sont adaptés aux réponses sélectionnées et restent indicatifs.
