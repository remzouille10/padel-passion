# Padel Passion

Petit site vitrine responsive en HTML, CSS et JavaScript, prêt à publier avec GitHub Pages.

## Fichiers
- `index.html` : contenu et structure du site.
- `style.css` : mise en page et styles responsive.
- `script.js` : menu mobile, année automatique et démonstration du formulaire.

## Tester sur son ordinateur
1. Décompresse `padel-passion.zip`.
2. Ouvre le dossier `padel-passion`.
3. Double-clique sur `index.html` pour ouvrir le site dans ton navigateur.

Aucune installation n'est nécessaire. Une connexion internet est nécessaire pour charger les polices Google Fonts.

## Publier gratuitement avec GitHub Pages
1. Connecte-toi sur https://github.com ou crée un compte.
2. Clique sur **New repository**.
3. Donne-lui le nom `padel-passion` et choisis **Public**.
4. Clique sur **Create repository**.
5. Dans le dépôt, clique sur **Add file**, puis **Upload files**.
6. Décompresse le ZIP sur ton ordinateur et glisse les fichiers `index.html`, `style.css`, `script.js` et `README.md` (pas le dossier ZIP lui-même) dans la zone d'envoi.
7. Clique sur **Commit changes**.
8. Ouvre **Settings** → **Pages**.
9. Dans **Build and deployment**, choisis **Deploy from a branch**.
10. Sélectionne la branche **main**, le dossier **/(root)**, puis clique sur **Save**.
11. Patiente quelques minutes. GitHub affichera l'adresse publique du site dans la section Pages, généralement `https://TON-PSEUDO.github.io/padel-passion/`.

## Modifier le site
- Textes et sections : `index.html`
- Couleurs, tailles et mise en page : `style.css` (variables au début du fichier)
- Interactions : `script.js`

## À savoir
Le formulaire d'inscription est une démonstration côté navigateur : il n'enregistre aucune adresse e-mail. Pour collecter réellement des inscriptions, il faudra le connecter à un service de newsletter ou à un backend. Le site n'utilise pas de base de données.
