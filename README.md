# Padel Track Pro — carnet et analyse de padel

## Mise à jour
Cette version ajoute :
- Formulaire de match en 4 étapes.
- Score détaillé set par set avec champs numériques adaptés au mobile.
- Statistiques de match : points gagnants, fautes directes, fautes provoquées, smashs, lobs, volées, fautes au service, points au filet/en défense et balles faciles manquées.
- Questionnaire tactique et ressenti : placement, communication, vitres, choix tactiques, physique, mental, meilleur coup et coup à travailler.
- Débrief après chaque match avec recommandations générées à partir des réponses saisies.
- Répertoire des joueurs et des clubs/lieux, matériel.
- Thèmes clair, sombre et crème, avec plusieurs couleurs d'accent.
- Recherche, statistiques de saison, export et import JSON.

## Installer sur GitHub Pages
1. Décompresse le ZIP sur ton ordinateur.
2. Ouvre ton dépôt GitHub `padel-track`.
3. Remplace les anciens fichiers avec les nouveaux : `index.html`, `style.css`, `app.js` et le dossier `assets`.
4. Ajoute/valide les modifications avec **Commit changes**.
5. Vérifie dans **Settings → Pages** que la publication est toujours réglée sur `main` et `/(root)`.
6. Attends la fin du déploiement, puis recharge ton application.

## Données et limites
Les données sont conservées dans le stockage local du navigateur sur cet appareil. Il n'y a pas encore de compte utilisateur, de sauvegarde cloud ni de synchronisation entre appareils. Utilise l'export JSON pour sauvegarder tes données et l'import pour les restaurer.
Les conseils sont des recommandations heuristiques fondées sur les réponses et les statistiques saisies. Ils ne mesurent pas automatiquement la technique et ne remplacent pas un coach. Pour améliorer la qualité de l'analyse, saisis seulement les chiffres que tu as réellement comptés.
